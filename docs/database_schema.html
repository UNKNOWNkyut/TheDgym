Table Specifications & Schemas

users Auth & IAM

System accounts with role-based access control (RBAC).

Column Type Key Description
id INTEGER PK Unique User ID
email VARCHAR(255) UK Login email (Unique)
hashed_password VARCHAR(255) Argon2id password hash
full_name VARCHAR(255) Full name
phone VARCHAR(50) Contact phone number
role VARCHAR(20) admin | staff | trainer | member
is_active BOOLEAN Account active state
created_at DATETIME Creation timestamp
updated_at DATETIME Last update timestamp
members Athletes Roster

Gym athlete demographics, membership code, and contact profiles.

Column Type Key Description
id INTEGER PK Unique Member ID
member_code VARCHAR(20) UK Identifier (e.g. DGM-0001)
first_name VARCHAR(100) First name
last_name VARCHAR(100) Last name
email VARCHAR(255) Email contact
phone VARCHAR(50) Mobile phone
date_of_birth DATE Birth date
gender VARCHAR(20) male | female | other
address TEXT Home address
emergency_contact_name VARCHAR(255) Emergency contact name
emergency_contact_phone VARCHAR(50) Emergency phone
status VARCHAR(20) active | inactive | suspended | expired
is_active BOOLEAN Active flag
notes TEXT Health notes / goals
joined_at DATETIME Registration date
membership_plans Tier Catalog

Pricing catalog and validity duration for gym subscriptions.

Column Type Key Description
id INTEGER PK Unique Plan ID
name VARCHAR(100) Plan name (e.g. Monthly)
slug VARCHAR(100) UK URL identifier
duration_days INTEGER Validity in days (1, 30, 365)
price_php NUMERIC(10,2) Price in Philippine Pesos
is_active BOOLEAN Available for enrollment
sort_order INTEGER Display ordering priority
member_memberships Subscriptions

Transaction records connecting members to plan subscriptions.

Column Type Key Description
id INTEGER PK Subscription ID
member_id INTEGER FK -> members(id)
plan_id INTEGER FK -> membership_plans(id)
start_date DATETIME Start validity
end_date DATETIME Expiration date
status VARCHAR(20) active | expired | cancelled
paid_amount NUMERIC(10,2) Amount paid (PHP)
payment_method VARCHAR(20) cash | gcash | maya | bank
payment_reference VARCHAR(100) OR # / Reference code
created_by_user_id INTEGER FK -> users(id) Staff recorder
visits Front Desk

Attendance logs, dwell times, and physical entry tracking.

Column Type Key Description
id INTEGER PK Unique Visit ID
member_id INTEGER FK -> members(id)
checked_in_at DATETIME Entry timestamp
checked_out_at DATETIME Exit timestamp
visit_type VARCHAR(20) walk_in | class | pt_session | open_gym
recorded_by_user_id INTEGER FK -> users(id) Staff on duty
notes TEXT Front-desk remarks
class_sessions Group Classes

Class schedules, coach assignments, and participant limits.

Column Type Key Description
id INTEGER PK Class Session ID
name VARCHAR(150) Class title
coach_id INTEGER FK -> users(id) Coach
class_type VARCHAR(20) barbell_club | conditioning | powerlifting...
scheduled_at DATETIME Scheduled date and time
duration_minutes INTEGER Length in minutes (e.g. 60)
max_capacity INTEGER Capacity limit (e.g. 15)
status VARCHAR(20) scheduled | ongoing | completed | cancelled
location VARCHAR(100) Turf, Platform 1, etc.
class_enrollments Junction Roster

Participant enrollment roster connecting members to group classes.

Column Type Key Description
id INTEGER PK Enrollment ID
member_id INTEGER FK -> members(id)
class_session_id INTEGER FK -> class_sessions(id)
enrolled_at DATETIME Registration timestamp
notes TEXT Member notes
pt_sessions Personal Training

1-on-1 personal training requests, coach approvals, and completion.

Column Type Key Description
id INTEGER PK PT Session ID
trainer_id INTEGER FK -> users(id) Assigned Coach
member_id INTEGER FK -> members(id) Athlete
scheduled_at DATETIME Session schedule
duration_minutes INTEGER Duration (min)
status VARCHAR(20) pending | confirmed | scheduled | rejected | completed
notes TEXT Member goals / requests
coach_notes TEXT Coach's programming notes
rejection_reason TEXT Declined reason if rejected
expense_categories Accounting

Overhead classifications (Equipment, Rent, Utilities, Maintenance).

Column Type Key Description
id INTEGER PK Category ID
name VARCHAR(100) Category Title
description TEXT Taxonomy notes
is_active BOOLEAN Active flag
created_by_user_id INTEGER FK -> users(id) Admin
expenses Disbursements

Ledger of financial disbursements and operational gym costs.

Column Type Key Description
id INTEGER PK Expense ID
category_id INTEGER FK -> expense_categories(id)
amount NUMERIC(12,2) Amount spent (PHP)
expense_date DATE Invoice / disbursement date
description TEXT Item description / Payee
receipt_path VARCHAR(500) Receipt file upload path
recorded_by_user_id INTEGER FK -> users(id) Admin
is_archived BOOLEAN Archived / soft-deleted
